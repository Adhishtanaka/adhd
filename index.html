What it does

One place to get small, messy jobs done.

Use plain language. adhd chooses the tools, shows its work, and asks before making changes.

⌁

Files and shell

Search, read, edit, and run commands inside folders you explicitly allow.

◎

Web and browser

Search the live web or operate a browser when a task needs current information.

◫

Memory

Keep useful preferences and project context locally between conversations.

↻

Flows and schedules

Turn repeatable work into visible workflows and run it now or later.

◇

Your model

Use DeepSeek, Anthropic, Gemini, or an OpenAI-compatible provider.

+

Skills and MCP

Add focused instructions and connect external tools without changing the core.

How it works

Local by default.
Explicit by design.

There is no hosted adhd service between you and your work. The app runs as one Bun process and stores its data under ~/.adhd/.

See the architecture →
  1. 01

    Start the local app

    Install the dependencies, add a provider key, and open localhost.

  2. 02

    Give it a task

    Chat normally. It selects only the tools the task requires.

  3. 03

    Stay in control

    Writes, shell commands, and browser actions pause for your approval.
